Guazi TV Personal Client

Guazi TV Personal Client is a private, non-commercial Android TV media browser developed for personal use.

The application uses TMDB only to enrich movie and television metadata, such as localized and original titles, posters, release dates, genres, ratings, cast and crew, and other descriptive information.

Video playback and media availability are handled independently from TMDB metadata. This project does not redistribute or sell TMDB data.

This product uses the TMDB API but is not endorsed or certified by TMDB.
