# Guazi TV Personal Client

Minimal public project page for a private, non-commercial Android TV media browser.

## GitHub Pages

1. Create a public GitHub repository, for example `guazi-tv`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save and wait for GitHub Pages to publish.

Your URL will normally look like:

`https://YOUR_USERNAME.github.io/guazi-tv/`

Use that URL in the TMDB **Application URL** field.
